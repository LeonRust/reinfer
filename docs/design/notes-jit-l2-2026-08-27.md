## 三、人工核查重点（按重要性）

1. **命中预算**：`jit_cache_reload_budget` 输出 `second provider (cache hit): <50ms`（实测 2.7ms，首建 154ms）。
2. **差分质量**：vec_add `worst abs err = 0e0`（位精确）；rms/rope/softmax 按 D7（fp32 rtol=1e-5/atol=1e-7）逐项；**掩码位语义 = 0**（`exp(-inf)` 数学结果，CPU/GPU 一致；全 masked 行为全 0）。
3. **确定性边界**：bit-exact 仅承诺"同机、同产物（同 key）、同 launch 配置"的 GPU-vs-GPU；GPU-vs-CPU 一律走 D7 容差。
4. **跨进程并发**：`concurrent.rs` 断言 compile 计数 ==1（两进程同 key 首发）。
5. **driver 三条实测纪律**（C3 发现，见 `jit.rs` 头注释，勿回退）：
   - launch 需线程 current primary context（`CtxGuard`）；
   - `CUkernel → CUfunction` 必须经 `cuKernelGetFunction`（直 cast → SIGSEGV）；
   - **kernelParams 必须以局部变量取址打包**（内联转换链值同内容也会在驱动内部 SIGSEGV——595.84 实测）。
6. **参数环境**：`REINFER_CUDA_NVCC` 必须指向 ≥12.8 工具链（PATH 是 12.6）；`REINFER_CUDA_ARCH` 默认 `sm_120a`。缺少时**梯度过旧 → Fatal（不静默降级）**——这是刻意行为。

## 四、已知边界（有意为之，回填生效）

- **启动阻塞式 prewarm**：延至 L3 引擎启动切片（012 r1 R8）；本切片=离线预烘焙+懒构建。
- **换机命中不承诺**：键不含系统头内容；`-M` 仅构建期漂移校验（R4）。
- **TuneDb 正式版**：006（本切片仅 TuneEntry 类型骨架）。
- **行式内核（1 block/行，≤8192）**：批量/多 head 分形到 L3 前优化；先正确后性能。
