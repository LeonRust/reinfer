## 二、其余采纳的单项修订

- 命名/引用：003 交叉引用 005↔006 全量修正；006 plan D1 "002 定"→"设计文档 §3.5+boundary §4"；005 "宪法 D2"→"设计报告 D2"；004 含 "spec 004/005 Dependency" 回指补全；feature-list 编号撞车修正（CPU 全环流→**007-core-inference**、CI→**008-ci-infra**、backlog 改写）
- TuneDb/select_* 归属：`crates/kernels`（A-H1）；tier 语义：003 的 nvcc 编译 CUDA C++ = **Jit 档**，选择链 Vendor(cubin) > Jit(CUTLASS FMHA) > Jit(dense/003 核)（A-M1）；003 契约 `launch_*` 标注 `crates/cuda`（A-M2）
- 模型/Engine 归属：`crates/engine`（forbid unsafe，005 切片建立）；`Sampler` 归 `crates/samplers`（A-M4/L2）
- 准入估值公式按 lightllm 口径完整落 spec（a,b 二元组、busy 阈值、EMA、峰值公式、token→页 ceil + page_size-1 slack、chunk 周期项声明）；vLLM 对拍仅限"每步计算预算"语义（C-中）
- 状态机：补 `Preempted`（仅记录，重算语义）、abort-after-done 幂等、`stop` 字符串放**调度层**（增量缓冲+部分匹配，延迟≤1步）、`n>1` 显式 4xx 拒绝并写入 API 文档（C-中）
- 指标定义：吞吐=调度层采样确认生成 token/墙钟（不含 prompt 与 SSE）；并发=已准入未完成；loadgen 统一 **64**（闭环，prompt 512，样本≥10k，预热 1k，同机，机型=runners 固定）；TTFT=到达→首 SSE delta；池基线=refcount>0 页数==0 且空闲页表长度==预热值；swap 页不计入（B-H3/M4/M5）
- Abort oracle：注入点 Waiting/Prefill(含 chunk 中)/Decode；断言=未 abort 请求与基线逐 token 一致 + 被 abort 请求 KV 引用归零（B-M7）
- Parity matrix 统一文档：模型（Llama-8B Q8_0/F16、Qwen2.5-1.5B Q8_0、SPM 档 Llama-2-7B）+ GGUF sha + prompt 集文件 + llama.cpp commit f280b2698/构建标志 + golden 路径 + 阈值，挂 specs/000/parity.md（B-L1/M3）
- tokenizer golden 改用 **llama-tokenize (`--ids`)**（本仓无 `-n 0` dump）；golden 存 id+piece；锚定 commit/gguf/convert 版本；CI 重建 diff 任务；SPM 降级或加 SPM 模型（本批次加 Llama-2-7B 档）；fuzz 分层（边界语料 ~50 条 + 随机 unicode + 随机 token-id 含越界）（B-M2/M3/M10，B-L5 锚定）
- 004/003 差异化案例澄清：每 kernel 三元组（输入/累积/输出 dtype）+ 判据表；删除裸 1e-5/1e-4/1ulp 混用（B-H2）
