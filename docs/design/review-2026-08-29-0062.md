## Verdict

No S1 correctness flaw (the flagged "temp=0 bit-identical" target was verified
**implementable** at code level: temp=0 consumes no RNG; both paths consume the
same logits under LogitsView). However **two structural S1 decisions** and
**13 S2 revisions** were raised; the adopted direction = "contract-first":

- **Adopt**: GPU sampler contract (G2/G4) this round — it is the only part the
  005 determinism anchor depends on **now**.
- **Defer to 006-2b**: decode-attn performance tier (G3) + fusion kernel group
  (G5) — re-open after 006 lands and ncu profile exists (their ordering and
  adoption thresholds all depend on measurements that do not exist yet).
- **Drop**: warp specialization (T5) — violates design-report D1 (Rust kernels
  for simple ops only); single-stream decode is bandwidth-bound, WS gains do not
  apply. Recorded as a decision, not a veto (re-open via new increment if profile
  later shows attn compute-bound >40 %).
- **Add**: T0 micro-benchmark prerequisite (isolated 003 naive decode-attn +
  llama.cpp CUDA reference; the 0.85× denominator was **never measured** — 014's
  referee is CPU-only) and Risk Assessment R1-R5 (diff-matrix growth / vendor
  license & KV-layout coupling / self-referential golden / time-boxes).

   (plan D2) vs current CPU `rand::StdRng` (ChaCha12). r2: three-tier wording

   (not a fork — wording fixed).

   r2 = **function-level** (same logits input); end-to-end stays under 014
   parity four layers. TV ≤0.05 below noise floor (n=640 null TV 0.06-0.13) →
   null-comparison/sample-size wording.

   (bias→penalties→bad words→temp→min_p→top_k→top_p→gumbel→argmax); uncovered
   params → explicit CPU fallback + notes. (agent A)

   contradiction (~1.5-2× = 545-726 tok/s) → ladder = expectation track only.
6. Count semantics: ≤4 kernel → per-layer ≤4 / per-step 4L+2 / graph = bucket
   node count; "≤1 launch 可选视图" → hard gate + counting rule (excl. lm_head).

   §3 row ownership also mismatched) → G1-G10 tags added, ownership rows fixed.
8. "020" dangling ref → removed (granted: no new SDK deps, 006 supply-chain).

   group-wide gain scale ≥max(5 %, 2× noise). (agent D)
